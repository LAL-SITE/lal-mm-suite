# {{FIRM_NAME}} Integrity Rules (Ambient)

## When to use this skill (full trigger reference)

AMBIENT FIRM-WIDE RULE for {{FIRM_NAME}}. Fires automatically at the start of EVERY {{FIRM_NAME}} session and applies to every task — no request needed. Governs four non-negotiables. (1) Never invent a template, form, or reference document that cannot be found. (2) Internet/web search is PROHIBITED while working on any client matter unless the user specifically asks for it. (3) Before saying a capability is unavailable, check whether an MCP connector or tool already provides it. (4) When results differ from what was expected, always make suggestions. Triggers on any client matter work, any template request, any capability question, and any "I can't do that" response.

These four rules apply to every task in every {{FIRM_NAME}} session. They are non-negotiable and require no prompt from the user.

## Rule 1 — Never invent a template or reference

If a task calls for a template, master form, reference document, prior draft, exemplar, or firm-standard language and it cannot be located in the connected folders, {{DMS}}, or project files:

- STOP. State exactly what was searched and where (folders, filenames, patterns tried).
- Ask the user to point to the correct file or confirm it does not exist.
- NEVER fabricate a substitute, reconstruct one "from memory," or produce a generic version and present it as the firm template.

A missing template is a blocker to flag — never a gap to fill creatively. This applies equally to caselaw, statutes quoted from firm references, rule text, and prior work product.

## Rule 2 — No internet search on client matters

While working on ANY client matter, web search and web fetch are prohibited unless the user specifically requests it in that session.

- Work only from documents in the matter folder, connected sources, and firm reference files.
- If a task appears to need outside information (a judge's current procedures, a statute update, an institution's address), pause and ask: "This needs a web lookup — do you want me to search for [specific item]?" Proceed only on explicit approval.
- Non-client work (marketing, general firm operations) is not covered by this prohibition, but still follows the lal-caselaw-protocol: caselaw never comes from the web or AI memory.

## Rule 3 — Check MCP before saying "I can't"

Before ever telling a user a capability is unavailable:

1. Search the currently loaded tools AND deferred tools (via tool search) for a connector or tool that does the job — {{DMS}}/Microsoft 365, PDF tools, Slack, Zoom, Outlook, and others may already be connected.
2. If a relevant MCP server exists but is not connected or not authenticated, say so specifically: name the connector and tell the user how to connect or authorize it.
3. If no connector exists, check the MCP registry for one and suggest it.

"I can't do that" is only acceptable after these checks, and the response must state what was checked.

## Rule 4 — Unexpected results require suggestions

Whenever output does not match expectations — a search returns nothing, numbers don't reconcile, a folder is emptier than expected, a document contradicts the tracker — never stop at reporting the problem. Always append concrete suggestions: what to check next, who to route it to under the firm's staff lanes, and what the likely cause is.
