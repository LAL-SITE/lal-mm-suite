# Circuit Starter File — Worked Example

**This is an example of a pattern, not a jurisdiction the product is built around.**

One circuit is used below so the pattern is concrete rather than abstract. The circuit shown —
Broward County, 17th Judicial Circuit — was picked as an illustration only. **It is not the product's
home jurisdiction, and nothing in this file should be read as a default.** Copy the pattern for
whichever circuit the firm actually appears in, and delete or replace this example once you have your
own.

**And it is a starting point to verify, never data to rely on.** It exists so the skill has somewhere
familiar to begin. It does not substitute for Step 2 of the skill — the live search sequence — which
runs every time regardless of what is written here.

## Circuit-level information (example)

- **Circuit:** 17th Judicial Circuit of Florida
- **County:** Broward
- **Official site (starting point):** 17th.flcourts.org — confirm this still resolves before relying
  on it; if it does not, search for the circuit's current official site by name rather than guessing
- **Family division directory:** search the official site for "Family Division judges" or "judicial
  directory." **This file does not and will not list current judges by name** — division assignments
  change often enough that any list here would be wrong, and a wrong list looks right.

For any other circuit, the same three lines are all that belongs at circuit level: circuit number,
counties, and a starting URL you have personally confirmed resolves.

**Never write a judge's or judicial assistant's name into this block.** Two reasons: names go stale
faster than anything else on the page and a stale name reads as current, and a judge's name recorded
next to matter information re-identifies the matter. Identify the officer by live search at the moment
of use.

## When an officer rotates or a division is renumbered

**Delete or visibly strike the old block rather than editing it in place.** A stale block carrying a
new date is worse than an obviously outdated one, because it looks current and nobody re-checks it.

Then:

1. Add a fresh block for the new assignment using the template above, with today's date and the source
   you verified it against.
2. Do not carry any field across from the old block. The outgoing officer's notice days, proposed-order
   format, and scheduling method do not transfer.
3. Note in the block if the circuit renumbered divisions rather than reassigning an officer — those are
   different events with different consequences for pending deadlines.
4. Re-run Step 2 of the skill for the incoming officer before relying on anything.

## The kind of circuit-specific reminder worth keeping (illustration)

Notes at this level are useful only when they describe **variation to check for**, not an answer. Good
examples, phrased the right way:

- The circuit may run a uniform motion calendar for some family divisions and not others. **Confirm
  whether the specific division uses UMC, an online portal, or direct chambers scheduling** — this is
  the kind of thing that varies judge to judge within one circuit.
  [CONFIRM LOCALLY: scheduling method for this division — with the judicial assistant]
- Family divisions in this circuit have used both in-person and remote hearing formats depending on the
  officer and the hearing type. **Never assume one.** Check the officer's current procedures and
  standing orders.
  [CONFIRM LOCALLY: hearing format for this hearing type — with the judicial assistant]
- Mandatory disclosure obligations are set by rule and do not vary by division, but some officers layer
  additional case management order deadlines on top. **Check for a case management order in the specific
  matter** rather than assuming the rule's timing controls.
  ⚠️ VERIFY: confirm rule and current text before relying on this.
  [CONFIRM LOCALLY: whether a case management order has issued in {{CASE_NO}} — with the clerk's docket]
- Where a circuit source appears to impose a local certification or disclosure requirement about the use
  of automated or generative tools, check whether a statewide rule and administrative order have made
  the statewide approach exclusive and prohibited local variations. If so, treat the local requirement
  as superseded and flag it rather than applying it, and report the obligation as the statewide signing
  representation instead.
  ⚠️ VERIFY: confirm rule and current text before relying on this.
  [CONFIRM LOCALLY: whether any local certification requirement remains in force — with the judicial
  assistant and with {{ROLE_APPROVER}}]

Notice that none of those four is an answer. Each one tells the reader what to go check. That is the
right register for this file.

## What does not belong in this file

- Judge, magistrate, hearing officer, or judicial-assistant **names**
- Remote meeting IDs, passcodes, or links presented as settled — they always carry the 48-hour flag
- Client names, case numbers, or opposing-party information — use {{CLIENT_NAME}} and {{CASE_NO}} in
  matter-specific work product, which lives in {{DMS}}, not here
- Case citations of any kind — those go through the caselaw protocol
- Anything copied from a non-official source
